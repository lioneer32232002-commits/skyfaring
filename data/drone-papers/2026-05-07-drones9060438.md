## 研究問題

多智能體 UAV 群集在複雜動態環境中的路徑規劃，需要同時滿足碰撞迴避、能耗最小化與任務時效三項目標。現有強化學習演算法在二維簡化場景下的表現已有研究，但從 2D 到具物理動力學的 3D 環境是否同樣適用，缺乏系統性的比較。本研究填補這個空缺，提供多演算法跨環境維度的完整評測。

## 數據來源 / 實驗平台

研究分兩階段進行：第一階段使用 Python 自建 2D 模擬環境，UAV 以空間點表示（模擬四旋翼），在靜態障礙物與多智能體衝突場景下導航；第二階段轉移至具物理引擎的 3D 模擬平台，採固定翼 UAV 真實動力學模型，配合路徑點導航任務進行評測。

## 方法 / 演算法

本研究比較五種強化學習演算法：PPO（Proximal Policy Optimization）、SAC（Soft Actor-Critic）、DDPG（Deep Deterministic Policy Gradient）、TRPO（Trust Region Policy Optimization），以及多智能體版本 MADDPG（Multi-Agent DDPG）。評測指標涵蓋獎勵最大化、碰撞迴避率與任務執行時間。

## 主要發現

- DDPG 在獎勵最大化與碰撞迴避兩項指標上表現一致優於其他演算法
- PPO 與 MADDPG 在任務執行時間效率上領先，適合對時效敏感的場景
- 從 2D 簡化環境移植至 3D 物理仿真時，各演算法相對表現排序出現明顯變化，顯示 sim-to-real 轉移是路徑規劃落地的關鍵挑戰
- MADDPG 的多智能體協作機制在密集群集場景下有優勢，但訓練穩定性較差
- 研究結果為自主系統開發與 UAV 群集導航的演算法選型提供了具體參考依據

## 摘要全文翻譯

多智能體 UAV 群集的路徑規劃，是一個在動態、充滿障礙物的環境中，如何以最少時間與能耗完成任務並同時避免碰撞的核心問題。本研究對多種強化學習（RL）演算法進行全面評測，分別在 2D 與 3D 模擬環境下測試多智能體 UAV 的路徑規劃表現。

第一階段，研究團隊以 Python 建立 2D 模擬場景，將 UAV（四旋翼無人機）抽象為空間中的點，讓它們在靜態障礙物與相互碰撞的約束下，各自導航至目標位置。第二階段則將實驗升級至具物理引擎的 3D 模擬環境，導入固定翼 UAV 的真實飛行動力學模型，並以路徑點方式進行導航測試。

研究比較了五種演算法：PPO（近端策略最佳化）、SAC（軟性行動者-評論者）、DDPG（深度確定性策略梯度）、TRPO（信任域策略最佳化），以及多智能體版本的 MADDPG（多智能體深度確定性策略梯度），分別在多種場景中評估。

結果顯示演算法之間在多個維度上存在顯著差異：DDPG 在獎勵優化與碰撞迴避上持續表現最佳；PPO 與 MADDPG 則在達成目標所需的執行時間上表現較優。此外，研究也揭示了從簡化的 2D 環境遷移至真實感更強的 3D 物理環境時，各演算法表現如何變化——這對「模擬到真實」（sim-to-real）的轉移至關重要。本研究為開發自主系統與 UAV 群集導航時的演算法選型，提供了具體的參考依據。

## 白話解釋（國高中生版）

想像你在玩一款多人闖關遊戲，十架無人機同時在空中飛，每架都要找到自己的終點，途中還有牆壁要繞過、還不能撞到其他隊友。這就是這篇論文想解決的問題。

難在哪裡？物理上，飛機不能走直線停下來，它有慣性——就像你騎腳踏車煞車，車子不會瞬間靜止一樣。所以「要去哪裡」和「怎麼飛過去才不撞牆」，是兩件必須同時計算的事。數學上，每架無人機的位置可以用座標 (x, y, z) 表示，它的速度和方向是向量，每一步要往哪飛，就是在解一個「讓損失最小、獎勵最大」的最佳化問題。

研究者用的工具叫做「強化學習」——概念跟遊戲打怪升等一樣。無人機每做一個動作，系統就給它分數：避開障礙得加分，撞到東西扣分，快速抵達目標多加分。透過反覆試錯，無人機慢慢學會哪條路最划算。

實驗分兩關。第一關是 2D，就像把無人機壓扁成一個點在棋盤上走；第二關升級成 3D，還加上真實的空氣動力學——固定翼飛機轉彎需要傾斜機身、不能原地旋轉，這讓問題難度大幅提升。

五種演算法就像五種不同策略的棋手：DDPG 最穩健，在兩個環境裡都能把碰撞壓到最低；PPO 和 MADDPG 跑得快，適合搶時間的任務。但有趣的是，在簡單 2D 裡表現好的演算法，換到 3D 之後排名不一定一樣——這告訴我們，在電腦模擬裡練習很好，但真正上天飛，還需要額外的調整。
