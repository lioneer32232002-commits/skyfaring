# 文章照片處理管線

2026-07 球鞋收藏文章驗證過的流程，之後的文章照片照這套做。目標：使用者隨手拍的照片，處理成同一組人在同一條件下拍出來的雜誌感。

## 裁切原則

- 文章內圖一律 16:9（輸出 1920×1080，JPEG quality 88，optimize）
- 構圖照商品攝影邏輯：主體佔畫面約三分之二、置中偏三分線，裁掉背景雜物（櫃子、雜物、地板反光）
- 每張裁完必須用 Read 開圖確認，不能只看座標數字

## 直式照片轉橫幅的兩招

1. 局部特寫：挑資訊密度最高的區塊（鞋舌標誌、吊牌、鞋帶區、後跟簽名），裁成橫幅細節照
2. 模糊背景延伸：整雙鞋要完整入鏡時，鞋身置中，背景用同一張圖放大、GaussianBlur(40)、亮度 0.55 填滿 16:9 畫布（雜誌內頁做法）

## 統一光線管線（不要太超過）

處理一律從原始上傳檔重新裁切再進管線，不對已輸出的檔案疊加處理。順序：

1. 白平衡：取每通道第 99 百分位當高光基準，增益夾在 0.85–1.2 之間、再打六折混合。上限是為了保護金色、螢光這類單色主導的照片不被灰世界假設校歪
2. 亮度：中位亮度向 132 靠攏一半，倍率夾在 0.85–1.18
3. 收尾：autocontrast(cutoff=1) 加 Color 1.04

做完拼一張 contact sheet（3×4 縮圖）整組檢查，確認沒有哪張被調過頭。實作參考此次 session 的 scratchpad `tone.py`（PIL＋numpy，約 40 行）。

## 圖說

網站 CSS 支援 `.prose p > img ~ em`：markdown 裡圖片下一行（不空行）接 `*圖說*`，會渲染成圖下小字灰色圖說。每張文章內圖都要配一行圖說，格式「型號／配色＋一句細節」，遵守寫作規範（無驚嘆號、無破折號、盤古之白）。

## 檔名

`sneaker-<品牌>-<型號>.jpg` 這類「主題-識別」格式，存 `public/images/`，與文章 slug 系統一致。hero 圖不得與其他已發布文章重複。
